# Future Network Map Home Concept

An optional later home mode can place an understated wireframe globe at center with the eight modules on a calm orbital grid. Thin phosphor lines connect modules to the globe; selected connections brighten slightly and expose a one-line status. It should remain typographic and quiet: no particle field, glass cards, chromatic neon, HUD brackets, or continuous camera motion.

Accessibility and performance constraints: the same numbered shortcuts remain authoritative, the layout linearizes for VoiceOver, Reduce Motion removes orbital transitions, and the terminal selector remains available as the default and fallback. This concept should be implemented only after the Study workflow is validated in daily use.
